# Privacy Notice

CareerFlow 保存用户主动提交的账户信息、简历、岗位 JD、生成材料、审批记录、任务状态和复盘，直到用户主动删除对应岗位或注销账户。

模型 API Key 默认以 AES-256-GCM 加密保存 8 小时；只有用户明确选择“保存”时才持久保存。浏览器不保存完整 Key。删除 Key 会删除临时和持久凭证记录。

只有在用户逐次确认后，简历提取文字、Evidence Library、JD 和必要上下文才会发送给用户选择的模型服务商。原始 PDF/DOCX 不发送给模型服务商，而由隔离文档服务处理。不同模型服务商的数据保存、训练与跨境政策由各厂商自行决定，使用前应阅读对应政策。

CareerFlow 不接收邮箱密码、不访问邮箱、不代用户发送邮件。生成的 `.eml` 和附件由用户下载并自行发送。

完整导出包含结构化数据、文件清单、哈希和短时下载地址。注销账户会删除数据库记录、私有对象和加密 Key；如果外部身份服务删除暂时失败，接口会明确报告，不能将其显示为完全完成。
